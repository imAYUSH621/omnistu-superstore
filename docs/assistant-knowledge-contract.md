# One Store knowledge boundary

The live automated assistant, legacy deterministic test entry and optional dormant NVIDIA product path now consume one source-mapped retrieval result: intent, language, availability state, public source routes, answer and a separate optional catalog-data string. All existing policy, order self-serve, contact, payment capabilities, shipping, account/recovery, language/currency, enquiry history, cart/address/checkout, category and product branches use that contract. This removes divergent English test answers and the route's separate four-chunk English model knowledge path.

Static policy/workflow answers, empty catalog and unavailable retrieval remain verbatim application answers even if an optional model is later enabled. The chat route no longer invokes private-order lookup, even if an old CHAT_ORDER_LOOKUP environment flag is present. It never reads private cart/address/order/enquiry state. A stored NVIDIA key or legacy ASSISTANT_TEST_MODE flag alone cannot activate a model: ASSISTANT_MODEL_ENABLED must explicitly be true, and deployments in this work force it false. This is a safety gate, not evidence of provider entitlement or owner approval to activate it.

Dormant product generation receives the same retrieved catalog string encoded as JSON and marked untrusted data, fixed source routes/state/language and only the current buyer query. Earlier conversation content and assistant messages are not sent to the provider. Model instructions forbid following catalog/visitor instructions or inventing stock, policies, actions, private-order facts and product paths. This limits exposure; it does not prove resistance to every prompt attack or make a model output a verified offer. No real provider call is made in qualification.

Local qualification covers actual shared retrieval across six languages, source mapping, all public branches, availability/empty/match, test-vs-closed checkout, current-only mocked provider payload, key/flag fail-closed behavior, private-order bypass prevention, legacy entrypoint parity and real route-to-retrieval assembly with a mocked DB boundary. Hosted proof checks the public path and same-source existing-isolated catalog separately, with real chat pixels. Model branch checks use mocked HTTP/SSE, never a real production model. This remains bounded deterministic/lexical retrieval, not semantic RAG, production model entitlement or whole-brief launch readiness.
